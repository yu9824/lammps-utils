LAMMPS Utilities#

lammps_utils is a Python package for LAMMPS (Large-scale Atomic/Molecular Massively Parallel Simulator) that provides utilities for data manipulation, analysis, and visualization.

lammps_utils.constants module#

Constants for working with atomic data and LAMMPS data file formatting.

This module provides: - The number of known chemical elements, - A mapping of element symbols to their atomic masses, - Data type mappings for parsing atom and bond sections in LAMMPS data files.

lammps_utils.constants.AVOGADRO = 6.022e+23#

Avogadro’s number (6.022 × 10²³) in units of mol⁻¹.

This constant represents the number of atoms, molecules, or other particles in one mole of a substance. Used for converting between atomic mass units and grams, and for density calculations.

lammps_utils.types module#

Type definitions for lammps-utils.

This module provides type aliases and type definitions used throughout the lammps-utils package.

lammps_utils.types.CellBounds#

Type alias for periodic cell bounds.

A tuple of three (lo, hi) tuples representing the lower and upper bounds for each axis (x, y, z) in a periodic simulation cell.

alias of tuple[tuple[float, float], tuple[float, float], tuple[float, float]]
